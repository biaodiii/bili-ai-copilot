# 直播AI搭档 · bili-ai-copilot

> 当前版本：**0.2.0**（2026-11）

一个给 **B 站直播间**用的桌面 AI 搭档：读取弹幕 → 调 DeepSeek 生成回复 → 显示在置顶悬浮窗上，
配一只会按情绪切表情的吉祥物；可选语音朗读、知识库检索、观众记忆。

<p align="center"><img src="默认素材图片/吉祥物大肥鱼/平常.png" width="180" alt="吉祥物·大肥鱼"></p>

> 不是无人值守的直播机器人：它只在你自己的电脑上跑，读你指定的一个直播间，用你自己的 API Key。
> 模型只负责"说"；**动配置、写知识库、联网这些有副作用的动作，都要你在界面上点头**。

## 功能

- 弹幕：游客 / Cookie 登录两种模式，WBI 签名 + brotli + 心跳 + 断线重连，**同一时刻只允许一条连接**
- AI：人设 / 多角色、上下文轮数、屏蔽词与触发模式、多条弹幕合并提问、回复只进悬浮窗（不发言）
- 悬浮窗：透明置顶、可穿透 / 锁定 / 拖动 / 四边缩放、对话区、12 个状态吉祥物；
  **无边框模式**只留吉祥物和回复、自动置顶（托盘/面板一键切换）
- 语音：系统语音 / 阿里云 Qwen TTS；只念本条回复的原话；**朗读排队**（执行播报不打断正在念的话）；
  「念一段话 / 存成音频」存到 `data/语音存档/`，可选**语气**（预设或自定义要求，只有 Qwen-Audio-3.x 认）
- 知识库：纯 markdown 一条一目；整理 / 校对只出建议；待审草稿逐条通过或批量处理；锁定 = 只读
- 其他：主动搭话、观众记忆、用量统计、日志轮转

## 快速开始

环境：Windows 10 / 11（x64），[Node.js](https://nodejs.org/) 18 以上。

```bat
安装依赖.bat
启动.bat
```

配置 3 步：填 DeepSeek API Key → 填直播间房间号并「开启弹幕监听」→ 显示悬浮窗。
B 站登录可选（不登录昵称显示 `***`）。

## 数据在哪

| 路径 | 内容 |
|---|---|
| `data/settings.json` | 配置（**含 API Key / Cookie，明文**，别发出去） |
| `data/观众记忆/` | 本场记录 + 老观众名册 |
| `data/语音存档/` | 「念一段话」保存的 wav + txt（txt 里记着用的语气） |
| `知识库/` | 知识条目（notes / pending / inbox） |
| `data/copilot.log` | 运行日志（5MB 自动轮转） |

## 测试与发布

npm run check           # 全量自检（750+ 项，不联网、不耗额度）

## 说明与边界

- 这条连接**收不到礼物 / 上舰 / 醒目留言 / 进场**事件（实测），只解析弹幕与在线人气。
- 未登录时昵称打码 `***`；观众记忆以昵称为主键。
- 系统语音（Web Speech）拿不到音频数据，所以「保存音频」只在云音色下可用；语气也只对云音色生效。
- 不要把 `data/` 提交或分享出去（含 API Key、Cookie、聊天记录）。
- 仅供个人直播 / 学习使用，请遵守 B 站与 DeepSeek 的服务条款。
