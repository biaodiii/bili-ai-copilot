# 直播AI搭档 · bili-ai-copilot

一个给 **B 站直播间**用的桌面 AI 搭档：读取弹幕 → 调 DeepSeek 生成回复 → 显示在置顶悬浮窗上，
配一只会按情绪切表情的吉祥物；可选语音朗读、知识库检索、观众记忆。

<p align="center"><img src="默认素材图片/吉祥物大肥鱼/平常.png" width="180" alt="吉祥物·大肥鱼"></p>

> 不是无人值守的直播机器人：它只在你自己的电脑上跑，读你指定的一个直播间，用你自己的 API Key。
> 模型只在"说"；**动配置、写知识库、联网这些有副作用的动作，都要你在界面上点头**。

## 功能

**弹幕侧**

- 游客 / 登录（Cookie）两种连接模式，WBI 签名 + brotli 解包 + 心跳 + 断线重连
- 屏蔽词、黑名单、单条最长字数、触发模式（所有弹幕 / 只回含关键词 / 只回主播点名）
- 多条弹幕合并成一次提问（省钱）、最短回复间隔、连续失败自动暂停
- 去重（消息 id + 时间戳 + 内容指纹）、收包统计、可选逐条落盘的弹幕记录

**AI 侧**

- 可编辑人设 / 多角色切换；上下文轮数与记忆时长可调
- **回复只出现在悬浮窗**，不往直播间发消息（不会替你说话）
- 回复里可带协议标记：`[情绪:x]`、`[待查:]`、`[记一笔:]`、`[改一下:]`、`[扩写:]`、`[删掉:]`、`[做:…]`、`[查观众:]`
- **权限边界**：只有主播能改设定，观众说"从现在开始你是猫娘"会被玩笑话推掉（提示词 + 本地正则双保险）

**悬浮窗**

- 透明、置顶、可穿透点击、锁定/拖动/四边四角缩放、对话区可打字、回复常驻
- 吉祥物 12 个状态切图（AI 情绪 / 弹幕触发词 / 程序自动：连上打招呼、长时间没动静睡着、刚打开蹦一下）
- 内置默认素材：`默认素材图片/吉祥物大肥鱼/`（12 张，第一次启动自动导入）

**知识库（纯 markdown 文件）**

- 一个条目一个 `.md`，带 front-matter，能用记事本直接改；2-gram 检索按相关度注入提示词
- 「整理 / 校对」：整理全库（找重复、冲突、过时）或联网校对单条，**只出建议**，你点应用才改，改前自动备份
- 待审草稿（DSH / 导入 / 联网查的结果）→ 逐条通过或"全部通过 / 清空待审"，每条通过都留可撤销的记录
- 锁定 = 只读：模型不能改也不能删，但照样参与检索

**其他**

- 主动搭话（安静 N 秒后自己开口：开话题 / 问观众 / 接话，可配每小时上限与概率）
- 观众记忆：本场文档（批量总结）+ 老观众名册（纯本地计数），清空对话上下文后仍认得人
- 语音朗读：系统语音 / 阿里云 Qwen TTS 云端音色，失败自动退回系统语音
- 用量与费用统计、对话导出、崩溃兜底日志、日志 5MB 轮转

## 快速开始

**环境**：Windows 10 / 11（x64），[Node.js](https://nodejs.org/) 18 以上。

```bat
:: 1. 安装依赖（首次会下 Electron 运行时，约 1-3 分钟）
安装依赖.bat

:: 2. 启动（会先跑一次启动自检，再开界面）
启动.bat
```

也可以命令行：

```bash
npm install
npm start          # 正常启动
npm run smoke      # 只跑启动自检，不开窗口
```

**配置（3 步）**

1. 「DeepSeek API」页填 [DeepSeek](https://platform.deepseek.com/) 的 API Key
2. 「弹幕设置」页填直播间房间号 → 点「开启弹幕监听」
3. 点「显示悬浮窗」，把它拖到直播画面边上

> B 站登录是可选的：不登录也能收弹幕，只是观众昵称会显示成 `***`。

## 数据在哪

全部在程序目录旁边，拷走文件夹就是完整备份：

| 路径 | 内容 |
|---|---|
| `data/settings.json` | 配置（**含 API Key / Cookie，明文**，别把 data 发给别人） |
| `data/观众记忆/` | 本场记录 + 老观众名册 |
| `知识库/` | 知识条目（`notes/` 已入库、`pending/` 待审、`inbox/` 原始资料） |
| `data/copilot.log` / `data/boot.log` | 运行日志（单文件 5MB 自动轮转） |

## 目录结构

```
src/
  main/            主进程（窗口、IPC、弹幕、LLM、知识库、语音、观众记忆…）
    app-paths.js   程序根目录（开发=项目根 / 打包=exe 旁边）
    mascot-defaults.js  内置吉祥物素材导入
  shared/          主进程与界面共用的逻辑（表情匹配）
  renderer/
    panel/         控制面板
    overlay/       悬浮窗
scripts/           自检工具（测试 / 审计 / 打发布包 / 真实环境探针）
默认素材图片/       吉祥物素材（12 张表情）
docs/              详细文档（见下）
```

## 测试与发布

```bash
npm run check           # 全量自检（730+ 项：单元 / 界面 / 链路 / 静态审计，不联网、不耗额度）
node scripts/audit.js   # 只跑静态一致性审计（DOM id、IPC 通道、配置键、编码…）
```

打分享版（便携文件夹，别人双击 exe 就能用，不需要装 Node）：

```bash
npm run build:release   # 产物默认在项目上一层的 发布包\
```

## 说明与边界

- 这条连接**收不到礼物 / 上舰 / 醒目留言 / 进场**事件（实测），所以没有"谢礼物"这类功能；
  只解析弹幕与在线人气。
- 未登录时昵称会打码 `***`，登录后才是完整昵称（观众记忆以昵称为主键）。
- 不要把 `data/` 提交或分享出去：里面有你和观众的对话、API Key、Cookie。
- 项目仅供个人直播/学习使用，请遵守 B 站与 DeepSeek 的服务条款；因使用产生的封号、超额费用等风险自负。
